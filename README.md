# FiaCasino

A personal, free-to-play, offline collection of games in one desktop application. The name is provisional.

Windows is the initial target. Godot + C# is the initial technology direction; a small prototype will validate the development and visual review workflow before game implementation.

## Current status

Project setup and collaboration documentation only. There is no runnable application yet, and no engine version has been pinned. Installation and run instructions will be added once validated.
