# Sample assets

The seven SVG card faces were created directly for this project. No downloaded artwork, fonts, or generated concept images are included in the application.

Each file is named after the card identity (`ace_of_spades.svg`, etc.). `CardView` loads the corresponding texture; game data does not derive identity from pixels. These are only the seven fixed preview cards, not a complete deck or an artwork selection system.

Godot provides the default interface font. Engine third-party notices are available at https://godotengine.org/license/.
